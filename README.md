# StuHelper Reviews

课程评价、导师评论、讨论、投票、收藏和草稿模块，提供 Go 服务、PostgreSQL Repository、HTTP Handler 与生成 SDK。课程目录、当前资格、内容审核和平台昵称通过公开接口注入。

课程评价绑定学期，教师仅取自请求人在该学期的可信选课记录。不指定教师时保存该学期任课教师并集。归属快照在重新发布时保持不变，管理员可依据当前权威来源预览并更正，保留原归属、来源修订和决定。导师评论只有文字，不参与课程评分。

教师评分先计算各课程均值，再对课程等权平均。接口只返回五级展示等级、样本量和课程数，分页查询分课程统计不改变总体结果。匿名公开结果不包含账号或选课证明。

首次发布后的编辑窗口默认 5 分钟。撤回隐藏整条讨论并保存 24 小时草稿，重新发布保留首次时间、回复和投票。过期读取立即拒绝，清理任务分批删除。普通草稿不使用这个期限。

编辑器可查询当前发布条件、可选教师和讨论内固定身份。普通草稿发布与草稿移除在同一事务完成，重复提交返回原评价。列表支持时间排序与绑定筛选条件的分页。管理员按学校权限读取原文并留审计，身份切换使用讨论内作者标识。

## 公开标签与教师回复

DisclosureProvider 提供当前认证状态、教师目录 ID 和逐字段来源、修订、有效期及公开授权。客户端只提交所选字段键，不提交标签值。数据库仅保存选择，展示时重新取得权威数据，已撤销或过期的授权不能继续公开。

学生可分别公开真实姓名、性别、所属学院和已选课程标识。没有权威选课记录时不能推断为未选。教师回复其他内容时，姓名、性别、教师标识和单位可独立选择。

认证教师回复本人曾教授课程的任何学期评价，必须公开真实姓名和教师标识。任课关系按 catalog 全部历史学期判断。必需信息或授权缺失时拒绝提交；已发回复随后失去必需授权时停止对外展示，并禁止新增回复或投票。作者仍可查看自己的记录。

## 管理功能

展示设置支持学校覆盖与全局默认，包括游客和成员预览长度、正文比例及八语言评分文案。配置保存检查独立权限、修订和幂等键。管理历史区分原文与处置说明；撤回内容的历史不能被原文接口旁路读取。

管理员可按当前选课来源更正评价教师归属，以及认定或撤销优质内容。目录合并后，旧评价仍可查询，统计先归并为同一课程再按课程等权计算。

候选接口为 0.2.0。新增 disclosure_required 状态扩展原固定枚举，消费者必须同步新的契约和生成类型，不能与 0.1.0 快照混用。该候选尚未发行。

## 使用与检查

```sh
make setup
bash scripts/check-with-postgres.sh
```

先修改 `contracts/reviews.openapi.json`，再执行 `make generate`。首次迁移由独立身份执行 `postgres.Schema`，运行身份仅访问 reviews schema。Handler 解析输入，Service 检查当前资格与对象状态，Repository 保存数据。

重复写入使用幂等键；同键不同内容拒绝。业务变化、审计、outbox 在同一事务提交。审核交接通过 Handoff 重试，审核决定按决定 ID 与内容修订拒绝重复效果和旧决定。

PostgreSQL 测试覆盖资格缺失、不同学期教师、匿名预览、身份继承、并发重复提交、统计、撤回、到期、草稿分页、投票和审核。测试使用合成身份与独立数据库。

真实身份和校园资格由应用提供。缺少事实或依赖时拒绝相应操作，不以演示身份代替。真实账号、存量迁移、备份恢复和压力基准仍待验收。

业务规则见 [课程与评价规格](https://github.com/StuHelper/stuhelper-next/blob/develop/docs/spec/academic-content.md)。
