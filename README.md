# StuHelper Reviews

课程评价、导师评论、讨论、投票和草稿模块，提供 Go 服务、PostgreSQL Repository、HTTP Handler 与生成 SDK。课程目录、当前资格、内容审核和平台昵称通过公开接口注入。

课程评价绑定学期，教师仅取自请求人在该学期的可信选课记录。不指定教师时保存该学期任课教师并集。归属快照在重新发布时保持不变，管理员可依据当前权威来源预览并更正，保留原归属、来源修订和决定。导师评论只有文字，不参与课程评分。

教师评分先计算各课程均值，再对课程等权平均。接口只返回五级展示等级、样本量和课程数，分页查询分课程统计不改变总体结果。匿名公开结果不包含账号或选课证明。

首次发布后的编辑窗口默认 5 分钟。撤回隐藏整条讨论并保存 24 小时草稿，重新发布保留首次时间、回复和投票。过期读取立即拒绝，清理任务按单讨论独立事务分批删除，管理员逻辑删除清除到期时间并保留审核历史。普通草稿不使用这个期限。

编辑器可查询当前发布条件、可选教师和讨论内固定身份。普通草稿发布与草稿移除在同一事务完成，重复提交返回原评价。列表支持时间排序与绑定筛选条件的分页。管理员按学校权限读取原文并留审计，身份切换使用讨论内作者标识。

新增投票和课程收藏要求当前内容准入。认证失效后，本人仍可查看已有记录并取消；取消操作只修改本人记录，不依赖资格服务、目标公开状态或目录可用性。

## 公开标签与教师回复

DisclosureProvider 提供当前认证状态、教师目录 ID 和逐字段来源、修订、有效期及公开授权。客户端只提交所选字段键，不提交标签值。数据库仅保存选择，展示时重新取得权威数据，已撤销或过期的授权不能继续公开。

学生可分别公开真实姓名、性别、所属学院和已选课程标识。没有权威选课记录时不能推断为未选。教师回复其他内容时，姓名、性别、教师标识和单位可独立选择。

认证教师回复本人曾教授课程的任何学期评价，必须公开真实姓名和教师标识。任课关系按 catalog 全部历史学期判断。必需信息或授权缺失时拒绝提交；已发回复随后失去必需授权时停止对外展示，并禁止新增回复或投票。作者仍可查看自己的记录。

## 管理功能

展示设置支持学校覆盖与全局默认，未配置时回退内置八语言（含阿拉伯语 RTL）五维评分文案模板。五维下标固定为推荐度、内容质量、课程难度、工作量和考核给分。

全局 `*` 配置返回 `source="global"`。保存配置检查学校授权、修订和幂等键。重试返回首次保存时的修订与实际生效文案。管理读取通过 AdminPresentation 校验学校与授权，写请求拒绝未知字段。

内容和配置接口不再提供旧预览字段。管理历史区分原文与处置说明，撤回内容的历史按当前状态授权。

管理员可按当前选课来源更正评价教师归属，以及认定或撤销优质内容。目录合并后，旧评价仍可查询，统计先归并为同一课程再按课程等权计算。

候选接口为 0.9.0，尚未发行。公共详情、列表、编辑器上下文、展示配置和统计要求当前内容准入；拒绝响应不包含正文、预览或统计。客户端需要同步契约和生成类型，并处理 401、403 与 503。

本人评价、草稿、投票回执不要求内容准入，但继续检查登录和归属。/reviews/me/votes 改为 OwnVote，只返回目标标识与本人投票值；其他作者的正文、身份和统计必须通过公共内容接口读取。

## 使用与检查

```sh
make setup
bash scripts/check-with-postgres.sh
```

先修改 `contracts/reviews.openapi.json`，再执行 `make generate`。首次迁移由独立身份执行 `postgres.Schema`，运行身份仅访问 reviews schema。Handler 解析输入，Service 检查当前资格与对象状态，Repository 保存数据。

重复写入使用幂等键，同键不同内容拒绝。所有外部依赖调用均设有独立超时上限并在入库事务及讨论锁外完成，入库事务内仅加锁核对版本并同事务提交业务变化、审计与 outbox。审核决定按决定 ID 与内容修订拒绝重复效果和旧决定。

PostgreSQL 测试覆盖资格缺失、不同学期教师、内容准入、本人记录例外、跨学校统计隔离、身份继承、并发重复提交、统计、撤回、到期、草稿分页、投票和审核。测试使用合成身份与独立数据库。

真实身份和校园资格由应用提供。缺少事实或依赖时拒绝相应操作，不以演示身份代替。真实账号、备份恢复和压力基准仍待验收。

业务规则见 [课程与评价规格](https://github.com/StuHelper/stuhelper-next/blob/develop/docs/spec/academic-content.md)。

展示配置包含评分文案、学校和修订，历史修订保存于审计表。

本人记录通过 /reviews/me/references 查询关联名称，每次最多 100 个 ID，任一 ID 无本人记录依据则整批返回 404。公开详情仍要求内容准入。

保存草稿时，服务端尝试按当前准入验证关联，验证失败不丢弃文字。reference_ids 只列出已验证关联，reference_state 说明验证状态。更换关联移除旧依据，历史草稿需恢复资格后保存验证。

账号注销通过受信模块端口持久登记匿名状态，同时删除普通草稿、撤回草稿与幂等回执。公开评价和管理视图均按匿名展示，并发中的新发布、草稿写入及后续管理员署名切换均受永久标记拦截。

## 独立收藏模块

收藏由 favorites 模块提供。本人名称查询通过 favorites 公开接口核对当前收藏归属，reviews 只访问自己的数据库。

账号注销后，投票使用逐条随机标识匿名保留并继续计入统计，本人回执同步清除。公开审计不记录普通作者与投票人账号，注销操作无需改写审计表，关闭标记阻止后续一切写入。

## 公开审计查询

AUDIT-01：postgres.Repository.ReadAudit(ctx, auditquery.Request) 返回 auditquery.Batch。backend 适配器负责认证，将当前授权与查询范围求交，再传入 Scopes。Repository 按范围并集与全部条件过滤后分页。

时间为左闭右开区间，每次最多 101 条，按时间、模块、ID 字节序降序。Before 使用全局位置。Snapshot 固定 PostgreSQL 已提交成员，排除回填和延迟提交；删除或修改审计使旧快照失效，调用方须重新查询。

摘要只含模块、内部对象、管理操作者标识、时间、操作、原因、结果与范围。用户内容与投票事件的操作者固定脱敏为 anonymous，匿名作者反查须通过受敏感能力保护的 accountquery 执行。

CheckRuntime 检查 audit、discovery_history 和 activity_history。运行身份具备任一列的 UPDATE 权限，或具备表级 DELETE、TRUNCATE 权限时，检查失败。行级与清空触发器维护清理修订。

postgres/audit_query_test.go 的 TestPublicAuditQuery 使用独立 PostgreSQL 数据库，验证条件筛选、范围、空原因、unknown、脱敏、回填与延迟提交、清理失效和取消。OpenAPI 路径保持现状，本接口供可信 Go 装配使用。

升级时，迁移身份先恢复旧回执的账号归属，再匿名化用户互动审计并清理已注销账号的私人草稿。管理处置审计保留操作者，重复迁移保持同一结果。

升级时清除已逻辑删除或隐藏评价遗留的撤回期限。审核历史保留原始版本，管理员仍可恢复现行记录。

管理员查看一次详情或历史，系统记录一条独立审计。同一时刻的多次查看分别留痕。读取历史时在讨论锁内核对当前状态，一次读取讨论身份并应用到各修订。

统计统一通过 ReadStatsPage 读取，调用方提供当前主体。学校范围在 SQL 分组前生效，评价的到期判断使用服务时钟。Go 调用方从 Stats 和 StatsPage 迁移到该入口。

浏览器写请求核对 Origin 的协议和主机，并拒绝跨站请求。带 JSON 正文的接口要求 application/json，可附字符集。TLS 在反向代理终止时，宿主需将受信的浏览器来源传入 Handler.PublicOrigin。
