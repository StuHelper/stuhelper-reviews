# StuHelper Reviews

课程评价、导师评论、讨论、投票和草稿模块，提供 Go 服务、PostgreSQL Repository、HTTP Handler 与生成 SDK。课程目录、当前资格、内容审核和平台昵称通过公开接口注入。

课程评价绑定学期，教师仅取自请求人在该学期的可信选课记录。不指定教师时保存该学期任课教师并集。归属快照在重新发布时保持不变，管理员可依据当前权威来源预览并更正，保留原归属、来源修订和决定。导师评论只有文字，不参与课程评分。

教师评分先计算各课程均值，再对课程等权平均。接口只返回五级展示等级、样本量和课程数，分页查询分课程统计不改变总体结果。匿名公开结果不包含账号或选课证明。

首次发布后的编辑窗口默认 5 分钟。撤回隐藏整条讨论并保存 24 小时草稿，重新发布保留首次时间、回复和投票。过期读取立即拒绝，清理任务分批删除。普通草稿不使用这个期限。

编辑器可查询当前发布条件、可选教师和讨论内固定身份。普通草稿发布与草稿移除在同一事务完成，重复提交返回原评价。列表支持时间排序与绑定筛选条件的分页。管理员按学校权限读取原文并留审计，身份切换使用讨论内作者标识。

新增投票和课程收藏要求当前内容准入。认证失效后，本人仍可查看已有记录并取消；取消操作只修改本人记录，不依赖资格服务、目标公开状态或目录可用性。

## 公开标签与教师回复

DisclosureProvider 提供当前认证状态、教师目录 ID 和逐字段来源、修订、有效期及公开授权。客户端只提交所选字段键，不提交标签值。数据库仅保存选择，展示时重新取得权威数据，已撤销或过期的授权不能继续公开。

学生可分别公开真实姓名、性别、所属学院和已选课程标识。没有权威选课记录时不能推断为未选。教师回复其他内容时，姓名、性别、教师标识和单位可独立选择。

认证教师回复本人曾教授课程的任何学期评价，必须公开真实姓名和教师标识。任课关系按 catalog 全部历史学期判断。必需信息或授权缺失时拒绝提交；已发回复随后失去必需授权时停止对外展示，并禁止新增回复或投票。作者仍可查看自己的记录。

## 管理功能

展示设置支持学校覆盖与全局默认，保留八语言评分文案。内容和配置接口不再提供 preview、guest_preview、member_preview 或 preview_ratio，包含旧配置字段的写请求会被拒绝。配置保存检查独立权限、修订和幂等键。管理历史区分原文与处置说明；撤回内容的历史不能被原文接口旁路读取。

管理员可按当前选课来源更正评价教师归属，以及认定或撤销优质内容。目录合并后，旧评价仍可查询，统计先归并为同一课程再按课程等权计算。

候选接口为 0.4.0，尚未发行。公共详情、列表、编辑器上下文、展示配置和统计要求当前内容准入；拒绝响应不包含正文、预览或统计。客户端需要同步契约和生成类型，并处理 401、403 与 503。

本人评价、草稿、投票回执不要求内容准入，但继续检查登录和归属。/reviews/me/votes 改为 OwnVote，只返回目标标识与本人投票值；其他作者的正文、身份和统计必须通过公共内容接口读取。

## 使用与检查

```sh
make setup
bash scripts/check-with-postgres.sh
```

先修改 `contracts/reviews.openapi.json`，再执行 `make generate`。首次迁移由独立身份执行 `postgres.Schema`，运行身份仅访问 reviews schema。Handler 解析输入，Service 检查当前资格与对象状态，Repository 保存数据。

重复写入使用幂等键；同键不同内容拒绝。业务变化、审计、outbox 在同一事务提交。审核交接通过 Handoff 重试，审核决定按决定 ID 与内容修订拒绝重复效果和旧决定。

PostgreSQL 测试覆盖资格缺失、不同学期教师、内容准入、本人记录例外、跨学校统计隔离、身份继承、并发重复提交、统计、撤回、到期、草稿分页、投票和审核。测试使用合成身份与独立数据库。

真实身份和校园资格由应用提供。缺少事实或依赖时拒绝相应操作，不以演示身份代替。真实账号、存量迁移、备份恢复和压力基准仍待验收。

业务规则见 [课程与评价规格](https://github.com/StuHelper/stuhelper-next/blob/develop/docs/spec/academic-content.md)。

展示配置迁移删除当前配置中的旧预览键，保留评分文案、学校和修订。历史配置作为审计记录保留；对外投影只包含当前契约字段。迁移可重复执行，运行身份不执行迁移。

本人记录通过 /reviews/me/references 查询关联名称，每次最多 100 个 ID，任一 ID 无本人记录依据则整批返回 404。公开详情仍要求内容准入。

保存草稿时，服务端尝试按当前准入验证关联，验证失败不丢弃文字。reference_ids 只列出已验证关联，reference_state 说明验证状态。更换关联移除旧依据，历史草稿需恢复资格后保存验证。

账号注销通过受信模块端口持久登记匿名状态。公开评价保留正文与讨论结构，不再返回个人主页或认证标签。并发中的新发布与后续管理员署名修改均受永久标记约束，原归属仅留在内部审核记录。

## 独立收藏模块

装配 favorites 后，原课程收藏 HTTP 入口转发到该模块。用户显式请求 favorites 的迁移接口后，才通过公开端口封存旧写入并分页迁移到默认收藏夹。普通列表读取不触发迁移。迁移进度可恢复，reviews 不读取 favorites 数据库。

旧回执仍在有效期内时返回原结果，避免重试已经取消的历史收藏时重新新增。封存后的旧行不再授予名称读取权限，名称查询通过 favorites 核对当前归属。移除转发入口需要客户端迁移完成后另行安排。

账号注销后，投票使用逐条随机标识匿名保留并继续计入统计。投票回执和审计中的账号关联同时清除，旧课程收藏删除并封存，关闭标记阻止后续投票和重新收藏。
