# 评分摘要与评价视图

## 批量摘要

GET /api/v1/reviews/summaries 接受 kind=course 或 teacher，以及一至一百个逗号分隔的 ids。重复 ID 与已合并别名归并，结果按规范 ID 排序。include_charts=true 增加五维分布和学期趋势。

每次请求重新检查当前学校内容准入。目标由 catalog 批量核验，其他学校返回 403，不存在、已停用或 T2 不可见的教师返回 404。查询只统计当前已发布且未过期的课程根评价，不包含回复或导师文字评论。

课程统计使用归并后的课程评价，查询前按规范 ID 展开关联别名并使用目标索引。教师统计使用发布时保存的 TeacherIDs 归属，先算各规范课程均值，再对有样本的课程等权平均。别名与规范教师同时出现在旧归属中时，每条评价仍只计一次。

响应返回 review_count、五维 Band 和四档 recommendation，不返回精确均值、账号、正文或选课证据。`statistics` 保留五档展示。评分图表和四档推荐使用批量摘要。

## 已确认的可调配置

`RecommendationPolicy` 默认样本门槛为 3。推荐度均值达到 4.5、3.5、2.5 时依次返回 `strongly_recommended`、`recommended`、`average`，低于 2.5 返回 `not_recommended`。样本不足返回 `unrated`。

阈值严格递增且在 1 至 5 内，样本门槛为 1 至 1000。服务启动时验证配置，错误配置拒绝启动。配置通过 backend 独立私有文件注入，响应 policy 显示实际使用的定义。

五维档位与图表也使用该样本门槛。分布只返回总样本数及五条相对长度，以最大柱为 20 并四舍五入，不返回每档精确人数或百分比。长度是绘图值，不应相加作为样本量。

趋势按学期返回名称、样本量、五维档位及推荐等级，最多一百个学期。每条评价只属于一个学期，因此各学期样本之和等于总体样本数。教师各学期内部仍按课程等权，不能再按学期等权推导总体。

## 目录端口与个人数据

DirectoryMetrics 是公开 Go 端口，按已授权学校一次返回非零对象聚合，最多十万个课程与目标组合。归并映射来自 catalog 公开接口，SQL 只读取 reviews。无跨请求缓存，撤回、隐藏、删除与过期在下次读取时移除。

GET /api/v1/reviews/me/overview 只使用认证主体。review_count 是本人已发布、未过期的课程及导师根评价数量。draft_count 与草稿箱一致，包括普通草稿和未过期撤回记录。

pending_courses 通过 catalog 的当前授权选课来源取得候选，排除本人已保存的非删除评价课程与学期组合，最多返回二十项及完整候选计数，并在已有普通草稿时附带 draft_id。重复选课按课程和学期去重，不限制再次评价的权限。

本人选课展示授权、选课来源、目录别名接口或资格未就绪及子调用超时时，pending_courses.state 为 unavailable，count 为 null，items 为空。本人评价与草稿数量仍可读取。接口不接受目标账号参数，也不从他人的选课推断本人的待办。

upvotes 排序使用触发器维护的赞数与复合索引。recommended 排序先展示精选，再按净赞同、赞同数、时间和 ID 降序排列。列表可按 featured、has_teacher_reply 与 rating_group 筛选，游标绑定原筛选条件。

列表剔除不可见回复后最多续读三次。列表和详情均须显式传入 include_teacher_ids=true 才返回课程评价的任课教师归属快照。默认响应保持原有字段。

本人评价列表和详情、管理评价列表、详情及历史接受 include_moderation_details=true。本人可读取结构化审核原因。管理员还可读取队列标志、父回复和更新时间。

新回复与最近动态由 notifications 提供。草稿正文通过 drafts 接口读取。

## 列表回复预览与通知名称

请求 include_reply_preview=true 时，评价列表中的已发布根评价增加 reply_count 和 reply_preview。reply_count 统计当前可见的全部回复，包括嵌套回复。reply_preview 最多三条，按创建时间、ID 升序，保留既有匿名、署名、投票和公开标签字段。

撤回、隐藏、删除、到期以及必需实名授权失效的回复不计入。本人列表在内容准入失效后仍提供本人的原有记录，同时省略其他用户的回复统计和预览。根评价分页及原游标保持不变。

Repository 对整页根评价批量检查教师回复，再批量读取计数与预览。计数与预览来自同一数据库快照，最多返回三百条回复。当前公开授权在每次请求内去重，结果不会跨请求缓存。

一页需要检查的教师与讨论组合超过一千个时返回 unavailable，避免无界访问资格服务。新出现且尚未核验的教师回复不会进入本次计数或预览。客户端可缩小分页并重试。

NotificationTitles 是供宿主使用的公开 Go 接口，每次接收一至一百个 ID，只返回当前可见的标题。回复使用根评价标题。接口检查当前学校准入、目录可见性、公开标签、根内容状态和修订，缺失或不可见对象省略。

学期摘要的 `term_order_key` 使用 catalog 的自然年乘十加季节顺序。`terms` 先按键倒序，再按 `term_id` 升序。未知键为零，排在已知学期后。

未指定 include_reply_preview 或设为 false 时，保持旧 View 结构且不读取预览。该参数只接受单个 true 或 false。Go 调用方通过 Filter.IncludeReplyPreview 显式选择增强结果。

## 体育项目评价

体育项目沿用 course 评价类型，target_id 使用 catalog 项目 ID。编辑器的 teacher_required=true 表示发布必须选择一个教师，teacher_ids 仍只包含本人同一项目及学期的任课教师。项目目录中的全部教师不能直接用作评价资格。

创建、草稿发布和修改均检查教师选择。缺少教师返回 invalid_input，其他教学班的教师返回 forbidden，缺少本人项目选课记录返回 enrollment_required。即使普通课程关闭选课要求，体育项目仍需选课依据。

原编号体育课程被目录规则排除后，详情、统计、列表、编辑器和新写入返回不存在。既有评价和草稿不自动转移到项目，迁移必须能够从原教学班明确还原项目并另行确认。

## 课程换号后的评价归属

REV-IDENTITY-01：catalog 的公开映射将新旧课程 ID 归为同一课程。列表同时读取等价引用，课程及教师统计先归并课程后计算。原始评价输入、学期、教师与选课证据保持不变。

创建评价按规范课程 ID 和规范化请求计算幂等键与摘要。新旧链接提交相同键和内容只产生一条评价，同时识别切换前使用旧 ID 的回执。同键不同内容被拒绝。已有记录的回执过期后，重放返回冲突，不创建重复评价。

业务回退保留数据库与课程映射，以保留切换后的写入。`REV-IDENTITY-01` 的隔离测试覆盖切换前记录、切换后写入、服务重建、统计及权限撤销。

指定目标的摘要优先按目录等价 ID 展开，只向 SQL 传入匹配别名。旧目录适配器按目标类型读取别名后筛选。服务对查询返回的课程和学期执行归并，保留各规范课程等权的统计规则。升级从既有投票重建赞数，从回执恢复到期时间。

本人列表按保存的课程、教师 ID 筛选。目录不可用或准入失效时仍可读取本人记录，资料服务不可用时省略个人资料。公开讨论按课程或导师目标解析，并按当前学校读取。

管理员预览与更正体育项目归属时都要选择本人选课证据覆盖的教师，教师别名按目录归并。预览返回前再次核实评价修订与期限，审计成功才返回结果。

编辑器先检查课程或导师目标是否停用。停用课程返回 forbidden，披露事实不可用时返回 unavailable；这些状态均禁止发布。

编辑器和本人概览接受 include_own_context=true 以返回本人的草稿与评价关联。评价列表与详情接受 include_parent_summary=true 以返回父楼层可见状态和讨论内标识。

## 追评

已发布且未到期的课程评价和导师评论主帖可以由作者提交 `append`。请求携带正文和当前修订，正文最多 4000 个字符，每条主帖最多 10 条。宿主可以在上限内降低条数并设置间隔。服务检查当前发布资格，原正文、评分和归属继续有效。

追评沿用主帖的学校审核规则。免审追评立即公开。先审后发的追评通过后公开，先发后审的追评立即公开并进入人工队列。审核决定绑定单条追评。主帖通过时只改变主帖。

支持 `include_appends=true` 的列表、详情和管理历史可返回追评。公开读取限已发布的追评，本人和获授权的管理员可以查看待审追评。`module.yaml` 的 `ACAD-08` 登记追评限制、幂等、独立审核与并发注销测试。
