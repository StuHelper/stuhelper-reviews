# 原型评分与本人待办

## 批量摘要

GET /api/v1/reviews/summaries 接受 kind=course 或 teacher，以及一至一百个逗号分隔的 ids。重复 ID 与已合并别名归并，结果按规范 ID 排序。include_charts=true 增加五维分布和学期趋势。

每次请求重新检查当前学校内容准入。目标由 catalog 批量核验，其他学校返回 403，不存在、已停用或 T2 不可见的教师返回 404。查询只统计当前已发布且未过期的课程根评价，不包含回复或导师文字评论。

课程统计使用归并后的课程评价。教师统计使用发布时保存的 TeacherIDs 归属，先算各规范课程均值，再对有样本的课程等权平均。别名与规范教师同时出现在旧归属中时，每条评价仍只计一次。

响应返回 review_count、五维 Band 和四档 recommendation，不返回精确均值、账号、正文或选课证据。已有 statistics 的五档展示协议保持兼容，新原型的雷达、等级与趋势统一使用新摘要。

## 已确认的可调配置

RecommendationPolicy 默认值已确认，status 为 Accepted。默认 minimum_samples=3，综合维度均值达到 4.5、3.5、2.5 时依次返回 strongly_recommended、recommended、average，低于 2.5 返回 not_recommended。样本不足返回 unrated。

阈值严格递增且在 1 至 5 内，样本门槛为 1 至 1000。服务启动时验证配置，错误配置拒绝启动。配置通过 backend 独立私有文件注入，响应 policy 显示实际使用的定义。

新摘要的五维档位与图表也使用该样本门槛。分布只返回总样本数及五条相对长度，以最大柱为 20 并四舍五入，不返回每档精确人数或百分比。长度是绘图值，不应相加作为样本量。

趋势按学期返回名称、样本量、五维档位及推荐等级，最多一百个学期。每条评价只属于一个学期，因此各学期样本之和等于总体样本数。教师各学期内部仍按课程等权，不能再按学期等权推导总体。

## 目录端口与个人数据

DirectoryMetrics 是公开 Go 端口，按已授权学校一次返回非零对象聚合，最多十万个课程与目标组合。归并映射来自 catalog 公开接口，SQL 只读取 reviews。无跨请求缓存，撤回、隐藏、删除与过期在下次读取时移除。

GET /api/v1/reviews/me/overview 只使用认证主体。review_count 是本人已发布、未过期的课程及导师根评价数量。draft_count 与草稿箱一致，包括普通草稿和未过期撤回记录。

pending_courses 通过 catalog 的当前授权选课来源取得候选，排除本人已保存的非删除评价课程与学期组合，最多返回二十项及完整候选计数。重复选课按课程和学期去重，不限制再次评价的权限。

本人选课展示授权、选课来源或资格未就绪时，pending_courses.state 为 unavailable，count 为 null，items 为空。本人评价与草稿数量仍可读取。接口不接受目标账号参数，也不从他人的选课推断本人的待办。

GET /api/v1/reviews 新增 sort=upvotes，按赞同数、时间、ID 降序分页。快速查看可使用 limit=1。列表仍执行原有内容与作者展示授权，游标绑定原筛选条件。

新回复和最近动态复用 notifications，草稿正文复用既有 drafts 接口。本任务不增加群聊或私信接口。

## 列表回复预览与通知名称

评价列表中的已发布根评价增加 reply_count 和 reply_preview。reply_count 统计当前可见的全部回复，包括嵌套回复。reply_preview 最多三条，按创建时间、ID 升序，保留既有匿名、署名、投票和公开标签字段。

撤回、隐藏、删除、到期以及必需实名授权失效的回复不计入。本人列表在内容准入失效后仍提供本人的原有记录，同时省略其他用户的回复统计和预览。根评价分页及原游标保持不变。

Repository 对整页根评价批量检查教师回复，再批量读取计数与预览。计数与预览来自同一数据库快照，最多返回三百条回复。当前公开授权在每次请求内去重，结果不会跨请求缓存。

一页需要检查的教师与讨论组合超过一千个时返回 unavailable，避免无界访问资格服务。新出现且尚未核验的教师回复不会进入本次计数或预览。客户端可缩小分页并重试。

NotificationTitles 是供宿主使用的公开 Go 接口，每次接收一至一百个 ID，只返回当前可见的标题。回复使用根评价标题。接口检查当前学校准入、目录可见性、公开标签、根内容状态和修订，缺失或不可见对象省略。

学期摘要增加 term_order_key，使用 catalog 的自然年乘十加季节顺序。terms 按键倒序、term_id 升序；未知键为零，排在已知学期后。
